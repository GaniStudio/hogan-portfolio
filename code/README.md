# 화면에서 보여 준 코드

포트폴리오 서비스 상세 페이지의 코드 구간에 나오는 파일입니다. 실제 서비스 저장소는 비공개라, 화면에서 보여 준 파일만 그대로 옮겨 두었습니다.

| 파일 | 서비스 | 하는 일 |
|---|---|---|
| `lms/admin-list-state.ts` | 100일 챌린지 LMS | 운영진 과제 목록을 불러올 때, 실패하거나 늦게 도착한 응답이 빈 목록으로 덮어쓰지 않게 상태를 관리합니다 |
| `lms/review-navigation.ts` | 100일 챌린지 LMS | 과제 검수 중 새 제출이 들어와도 다음에 볼 미검수 과제 순서가 흔들리지 않게 고릅니다 |
| `words/testEngine.js` | 단어력 테스트 | 레벨에 맞는 단어를 고르고, 이미 낸 단어와 분야가 겹치지 않게 문제 카드를 만듭니다 |

LMS 두 파일은 같은 폴더의 `admin-filter`를 불러옵니다. 발췌 파일이라 이 폴더만으로는 실행되지 않습니다.
