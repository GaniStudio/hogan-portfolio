# Ho Gan Portfolio

허간의 교육 서비스 기획, 개발 과정과 AI 협업 경험을 소개하는 웹 포트폴리오입니다.

## Website

https://ganistudio.github.io/hogan-portfolio/

## Structure

- `index.html`: main portfolio
- `about/`: biography and career
- `projects/words/`: Vietnamese vocabulary test case study
- `projects/student-db/`: student database case study
- `projects/lms/`: 100-day challenge LMS case study
- `presentation/`, `student-db/`, `operator-db/`, `lms/`: isolated service demonstrations
- `licenses/`: third-party notices

The repository contains the static website and the JavaScript/CSS used to run it. Service demonstrations use fictional records and do not connect to operating student systems. Private working documents, captures, experiments and student curriculum PDFs are excluded.

## Hosting

GitHub Pages serves the `main` branch root. Paths use `/hogan-portfolio/`. No server, account credentials or environment variables are required.
